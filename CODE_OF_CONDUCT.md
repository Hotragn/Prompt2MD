# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment of any kind.
Report unacceptable behavior to the maintainers via a private GitHub report;
maintainers will review and respond within a week and may warn, moderate, or
ban as proportionate.
