[span] The Mechanism
[h2] How a document becomes cheap context
[p] Five stages. The interesting one is the third: the pipeline checks its own work and escalates when the cheap engine got it wrong.
[h3] Sniff
[p] Cheap byte-level probes read the content itself, never the file extension.
[h3] Route
[p] Fast path for text-layer PDFs, HTML, Office, CSV. High-fidelity path for scans and complex tables.
[h3] Escalate
[p] The fast path's output is inspected for damage. Degraded tables or low yield trigger a re-run on the heavy engine.
[h3] Optimize
[p] Boilerplate, navigation chrome, signatures, and duplicated passages come out. Structure stays.
[h3] Layout
[p] Stable content first, volatile last, provider-specific cache breakpoints in between.
[span] The Proof
[h2] Built for context budgets, not demos
[h3] Token cost is an output, not a footnote
[p] Every conversion returns a report: tokens in, tokens out, compression ratio, per-section costs, and the effective cost of each repeat call under your provider’s cache pricing. Set a budget and it is enforced, not suggested.
[h3] Lossless by construction
[p] Originals are stored content-addressed before anything is transformed. Summarized sections carry
[code] p2md:src
[p] anchors that resolve to exact bytes.
[h3] Dual-engine routing
[p] ~0.6 s fast path for most inputs; TableFormer and OCR only when the content proves it needs them.
[h3] Cache-aware layout
[p] Sections are ordered so prompt caches hit. Repeat calls can cost a fraction of the first one.
[h3] Works with nothing installed
[p] No API key, no sidecar, no account. With zero configuration you get deterministic cleanup and honest numbers; add an LLM gateway and the same pipeline restructures far more aggressively. Text input never hard-fails.
